A.13 Conventions

  • Multiplicative vs. additive notation: When a group operation is written as ∗ or ×, we use gⁿ for repeated application. When written as +, we use ng instead. Elliptic curve groups use additive notation.
  • Modular arithmetic: We write a ≡ b (mod n) to mean n divides a − b.
  • Hexadecimal: Prefixed with 0x, e.g. 0xFF = 255.
  • Keys: Private keys are written d, public keys P = dG, and signing nonces k, throughout the book.
  • Confirmations: Chapter 14 writes the confirmation count as z (following the whitepaper); later chapters use k. The two are the same quantity.
  • Minus sign: Mathematical subtraction and negation use the minus sign −; hyphens appear only in prose and numeric ranges.
